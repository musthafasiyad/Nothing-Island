# Nothing Island

A native Android Dynamic Island-inspired experience built with Kotlin and Jetpack Compose.

## Project

- Project: Nothing Island
- Package: com.nasx.nothingisland
- Language: Kotlin
- UI: Jetpack Compose
- Development IDE: Android Studio

## Current Progress

### v6.0 – Native Android Prototype
- Initial Android application
- Nothing-inspired dark interface
- Expandable Island UI

### v6.1 – Interactive Edition
- Interactive Music Island demo
- Notification preview
- Battery and Map feature previews

### v6.2 – Battery Edition
- Real device battery percentage
- Charging and discharging status
- Battery progress indicator

### v6.3 – Notification Edition
- Notification listener service
- Live notification title and message previews

### v6.4 – Visual Notification Edition
- Application launcher icons
- Improved notification cards

### v6.5 – Smart Controls
- Individual feed dismissal
- Clear All feed control
- Open sending application action

## Important

This is an ongoing development project. Some features are demos, and system-wide overlay, real media integration and live navigation are still under development.
